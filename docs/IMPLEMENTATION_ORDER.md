# Ordre d'implémentation UI

1. Accueil/dashboard : retirer les éléments sans valeur métier et structurer les panneaux.
2. Recherche individus : retirer les avatars décoratifs et rendre les colonnes utiles expansibles.
3. AUI : séparations plus lisibles, docking stable, perspectives versionnées.
4. Reflow : texte/contrôles/layouts réellement adaptatifs.
5. Icônes : migration explicite contrôle par contrôle ; suppression à terme de la substitution globale temporaire.
6. Planning semaine et échéancier.
7. Module Messagerie optionnel.
