# Upgrade Noethys

Ce répertoire contient les contrats d'architecture adoptés pendant la modernisation progressive de l'interface et des modules desktop.

- `UPGRADE_UI_UX_RULES.md` : règles générales de refactorisation UI/UX wxPython.
- `DASHBOARD_MODERNISATION.md` : trajectoire du nouvel accueil opérationnel.
- `MAIL_MODULE_ARCHITECTURE.md` : architecture cible de la messagerie optionnelle.
